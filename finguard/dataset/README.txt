Place the raw datasets here ONLY if you want to retrain the models:
  - creditcard.csv          (Kaggle credit card fraud dataset, 284,807 rows)
  - marketing_campaign.csv  (customer marketing campaign dataset, 2,240 rows)

You do NOT need these to run the app -- the trained model artifacts are
already included in backend/model/ and backend/data/. This folder is only
needed if you run train_fraud_model.py / train_personas.py again.
